# Flutter Ticket Booking Lab 2

**Student:** Zhang Jiaqian  
**Course:** SSW3401 Mobile Application Development  
**Lab:** Lab 2 Understanding the Basics of Flutter GUI

This project is a Flutter ticket-booking interface inspired by the assigned course video through the point where an image is displayed on screen. It demonstrates:

- a `MaterialApp` and `Scaffold`
- a responsive header built with `Row`, `Column`, `Container`, and `Text`
- local image assets loaded with `Image.asset`
- a selectable bottom navigation bar using `setState`
- styled sections, padding, rounded corners, and color themes

## Run the app

```bash
flutter pub get
flutter run
```

The project targets Android and has no third-party runtime dependencies.
